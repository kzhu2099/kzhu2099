# About Me

I work with astronomical data to investigate what can be inferred from small changes in brightness and timing. My projects have included TESS exoplanet searches, transit analysis, candidate vetting, and model development.

My more recent research interests include transit timing, binary-star systems, stellar variability, and asteroseismology.

## Selected Research Projects

- **[Exoplanets](https://github.com/kzhu2099/Exoplanets)**: An earlier TESS research project involving light-curve analysis, transit searches and fitting, candidate vetting, and tests of alternative explanations for potential transit signals. This repository preserves the code and results from that stage of my research.

- **[ExoRM](https://github.com/kzhu2099/ExoRM)**: An experimental project exploring estimates of exoplanet mass from radius. It includes spline-based model development and comparisons with Chen & Kipping's Forecaster. The project is archived and is not intended to replace established models.

## Research Interests

- Binary-star systems and stellar variability
- Asteroseismology and white-dwarf pulsations
- Scientific analysis of astronomical time-series data
