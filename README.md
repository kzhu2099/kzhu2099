# About me

I work with astronomical data to investigate what can be inferred from small changes in brightness and timing. My projects have included TESS exoplanet searches, exoplanet transit analysis, candidate vetting, and exoplanet model development.

My more recent research interests include characterizing, stellar variability, and asteroseismology on top of work expanding on my previous research projects.

## Some research projects I've done

- **[Exoplanets](https://github.com/kzhu2099/Exoplanets)**: An earlier TESS research project involving light curve analysis, transit searches and fitting, candidate vetting, and tests of alternative explanations for potential transit signals. This repository preserves the code and results from that stage of my research.

- **[ExoRM](https://github.com/kzhu2099/ExoRM)**: An experimental project exploring estimates of exoplanet mass from radius. It started with splines but now is centered on probabilistic prediction and comparisons with Chen & Kipping's Forecaster. The project is archived and is not intended to replace established models.
